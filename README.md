# Next.js 15 SEO Template

Production-ready SEO template for Next.js 15 App Router.

## Features

- ✅ Schema.org structured data (Organization, WebSite, FAQPage)
- ✅ Open Graph and Twitter Cards
- ✅ Automatic sitemap.xml generation
- ✅ robots.txt with AI crawler allowances
- ✅ Core Web Vitals optimized
- ✅ Image optimization with next/image
- ✅ Font optimization with next/font

## Quick Start

```bash
npx create-next-app my-app -e https://github.com/mrdave001/nextjs-seo-template
```

## SEO Checklist Included

- Meta titles with template pattern
- Meta descriptions on every page
- Canonical URLs
- Hreflang for i18n
- BreadcrumbList schema
- Article schema for blog posts

## Performance

- Server Components by default
- Streaming SSR
- Edge Runtime support
- Image optimization
- Font subsetting
